# Application starters

Prototypes of the apps listed on the Authdog docs home. Each folder is an identity starter for one stack. A signed-in session is not a permission grant.

| Folder | App |
| --- | --- |
| [nextjs](nextjs/) | Team dashboard |
| [react](react/) | Customer navbar |
| [remix](remix/) | Support inbox |
| [expo](expo/) | Field companion |
| [sveltekit](sveltekit/) | Member site |
| [tanstack-start](tanstack-start/) | Ops console |
| [vue](vue/) | Workspace settings |
| [angular](angular/) | Admin console |
| [astro](astro/) | Handbook |
| [gatsby](gatsby/) | Resource library |
| [redwood](redwood/) | Job board |
| [express](express/) | Orders API |
| [fastify](fastify/) | Inventory API |
| [fastapi](fastapi/) | Booking API |
| [django](django/) | Clinic portal |
| [flask](flask/) | Status board |
| [starlette](starlette/) | Intake service |
| [aiohttp](aiohttp/) | Event ingest |
| [go](go/) | Billing service |
| [rust](rust/) | Policy service |

Copy one folder, set the public key from `.env.example`, and follow that folder's README.
